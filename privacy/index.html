Privacy

Last updated November 15, 2026

THIS WEBSITE

This website has no analytics or tracking scripts, sets no cookies, does not use browser storage, and has no forms. Its pages, fonts and images are all served from this website; it does not load scripts, fonts, embeds or other content from other websites.

The home page includes a few small interactive details that run entirely in your browser. They do not record, store or send your keystrokes or clicks.

HOSTING

This website is hosted by GitHub Pages. When you visit, your browser connects to GitHub’s servers, which receive standard connection information such as your IP address. GitHub states that it logs and stores the IP addresses of visitors to GitHub Pages sites for security purposes. GitHub’s handling of that information is described in its own privacy documentation.

DOMAIN NAME

Cloudflare provides the authoritative DNS for rance9.com: the service that answers when a device looks up where this website is. Cloudflare processes information about those lookups, such as the name and record type requested and the source IP address of the lookup, which is usually that of the DNS resolver your device uses. The website’s DNS records are set to DNS only, so Cloudflare does not proxy or handle the page requests themselves; your browser connects directly to GitHub Pages.
